# Косоглазие: прототип M3

M0: камера → MediaPipe Face Landmarker → контуры и числа радужек, режим `isDev`.
M1: масштаб (размер радужки), личная модель лица, поза, угол каждого глаза, личный ноль, вергенция в ПД; тесты на синтетике (`src/core/`, `tests/`).
M2: точная калибровка (поле зрения камеры, размер пикселя экрана, коэффициенты глаз по сетке 3×3). M3: детектор срыва, замер «срыв при отдалении», упражнение 1, сессия «до → упражнение → после».
Следующие этапы (M4+) не начаты.

## Запуск
```
npm install        # создаст package-lock.json, его нужно закоммитить (CI использует npm ci)
npm run typecheck
npm test           # тесты математики на синтетических данных
npm run build      # esbuild → dist/; скачает модель face_landmarker.task в .cache/
npm run serve      # http://localhost:8080
```
Android: USB + `chrome://inspect`, проброс порта 8080 (камере нужен localhost или HTTPS) либо деплой на GitHub Pages.

## Деплой
Push в `main` → `.github/workflows/deploy.yml` (npm ci, сборка, официальные Pages-действия). В настройках репозитория: Pages → Source: GitHub Actions.

## Проверка M0 (главный риск плана)
1. Несколько людей без косоглазия: числа стабильны? Шум dx/dy в состоянии покоя (± в панели).
2. Сильно отклонённый глаз: окно «глаза» (кропы) показывает, лежит ли метка радужки на реальной радужке или «тянется» к типичному положению.
3. Сцены с меткой в CSV: «оба открыты», «правый закрыт», «левый закрыт», «срыв». Запись → CSV (только числа).

Соглашения: dx > 0 в сторону носа для обоих глаз, dy > 0 вверх; правый/левый по человеку; зеркалится только превью.
Вергенция (сведение/разведение) = R_dx + L_dx; версия (общий поворот взгляда) = R_dx − L_dx.

## Калибровка (M1.5)
Меню ☰ → «Калибровка». Мастер из трёх шагов, каждый с описанием «зачем», кнопкой «Начать», таймером 3 с до старта и автостопом. Рамка по краю экрана: красная идёт запись, зелёная закончено. Звука и вибрации нет.

| Шаг | Как часто | Хранится | Пропуск |
| --- | --- | --- | --- |
| Размер радужки (11,7 мм по умолчанию, ввод или карта) | один раз на человека | localStorage | если записан |
| Модель лица (8–10 с поворотов головы) | один раз на человека и камеру; заново при смене камеры, очков, бороды | localStorage | если есть и камера та же |
| Ноль (оба глаза в камеру, 6 с) | в начале каждой сессии | только память страницы | если задан в этой сессии |

Карта: прижать к щеке рядом с глазом, смотреть в камеру; кадр замирает, четыре кружка перетаскиваются на углы карты (сверху лупа); наклон и поворот карты учитываются.
Журнал CSV один: при каждом запуске мастера очищается; сцены (`iris_card`, `face_model`, `zero`) ставятся автоматически. Скачать: меню → «Скачать CSV калибровки». «Разработка» в меню: isDev, разрешение, FOV, запись сцены с меткой (`dev:метка`, добавляется в тот же журнал), снимок.

Деплой: Node 24, ветка `master`.

## Точная калибровка (M2)
Меню ☰ → «Точная калибровка» (нужны радужка и модель лица). Шаги: 1) поле зрения камеры по линейке (необязательно, по умолчанию 63°); 2) размер пикселя экрана (карта на экране или диагональ); 3) коэффициенты глаз: сетка 3×3 по очереди каждым глазом (второй закрыт), ближняя дистанция 30–50 см; 4) то же на дальней 50–75 см (можно пропустить). Результат хранится для камеры. Вертикальный коэффициент подбирается только во весь экран. На узком экране (телефон вертикально) размах углов около 7°, поэтому коэффициент менее точен: лучше ноутбук или телефон горизонтально.

## Замер и тренировка (M3)
Меню → «Замер срыва (3 попытки)» или «Тренировка (сессия)». Нужны калибровка и ноль в этой сессии. Первый раз показывается предупреждение о противопоказаниях. Попытка: 3 с до старта, красная рамка до срыва и возврата (не дольше 30 с), результат в см. Порог срыва: не меньше 3° и 3σ шума нуля. Сессия: замер «до» (3) → упражнение 1 (5) → замер «после» (3). Направление (отдаление/приближение) в «Разработка». В CSV столбцы `dev_inst` и `event` (`break`, `return`, `mark`).
