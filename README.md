# Косоглазие: прототип M3

M0: камера → MediaPipe Face Landmarker → контуры и числа радужек, режим `isDev`.
M1: масштаб (размер радужки), личная модель лица, поза, угол каждого глаза, личный ноль, вергенция в ПД; тесты на синтетике (`src/core/`, `tests/`).
M2: расстояние по известному размеру (поле зрения камеры), размер экрана и коэффициенты глаз по сетке 3×3 (вошли в единый мастер). M3: детектор срыва, замер «срыв при отдалении», упражнение 1, сессия «до → упражнение → после».
Следующие этапы (M4+) не начаты.

## Запуск
```
npm install        # создаст package-lock.json, его нужно закоммитить (CI использует npm ci)
npm run typecheck
npm test           # тесты математики на синтетических данных
npm run build      # esbuild → dist/; скачает модель face_landmarker.task в .cache/
npm run serve      # http://localhost:8080
```
Android: USB + `chrome://inspect`, проброс порта 8080 (камере нужен localhost или HTTPS) либо деплой на GitHub Pages.

## Деплой
Push в `main` → `.github/workflows/deploy.yml` (npm ci, сборка, официальные Pages-действия). В настройках репозитория: Pages → Source: GitHub Actions.

## Проверка M0 (главный риск плана)
1. Несколько людей без косоглазия: числа стабильны? Шум dx/dy в состоянии покоя (± в панели).
2. Сильно отклонённый глаз: окно «глаза» (кропы) показывает, лежит ли метка радужки на реальной радужке или «тянется» к типичному положению.
3. Сцены с меткой в CSV: «оба открыты», «правый закрыт», «левый закрыт», «срыв». Запись → CSV (только числа).

Соглашения: dx > 0 в сторону носа для обоих глаз, dy > 0 вверх; правый/левый по человеку; зеркалится только превью.
Вергенция (сведение/разведение) = R_dx + L_dx; версия (общий поворот взгляда) = R_dx − L_dx.

## Калибровка (единый мастер)
Меню ☰ → «Калибровка». Пять шагов; каждый объясняет, что даёт, имеет кнопку «Начать», таймер 3 с до старта и автостоп. Рамка по краю экрана: красная идёт запись, зелёная закончено. Звука и вибрации нет. Кнопка «Пропустить» есть, только если значение уже записано (или шаг по желанию).

| Шаг | Что даёт | Как часто | Хранится | Пропуск |
| --- | --- | --- | --- | --- |
| 1. Размер радужки (11,7 мм, ввод или карта у щеки) | пиксели в миллиметры | один раз на человека | localStorage | если записан |
| 2. Расстояние до камеры (лист A4 29,7 см или линейка) | поле зрения камеры: расстояния в см | один раз на камеру и разрешение | localStorage | если записано |
| 3. Модель лица (10 с поворотов головы) | поза головы и масштаб в каждом кадре | один раз на человека и камеру | localStorage | если есть, камера та же, поле зрения то же |
| 4. Ноль (оба глаза в камеру, 6 с) | точка отсчёта отклонения | в начале каждой сессии | только память страницы | если задан в этой сессии |
| 5. Уточнение углов (по желанию): размер экрана по карте + сетка 3×3 каждым глазом | коэффициенты глаз: углы в градусах точнее | на устройство, редко | localStorage | всегда (углы тогда ориентировочные) |

Расстояние в шаге 2 считается до плоскости глаз (скула рядом с глазом), не до носа: нос ближе к экрану. Размер экрана (шаг 5) нужен только для сетки, к расстоянию не относится.
Журнал CSV один: при запуске мастера очищается; сцены (`iris_card`, `distance`, `face_model`, `zero`, `grid_right`, `grid_left`) ставятся автоматически. Скачать: меню → «Скачать CSV калибровки». «Разработка» в меню: isDev, разрешение, направление срыва, запись сцены с меткой (`dev:метка`), снимок.

## Замер и тренировка (M3)
Меню → «Замер срыва (3 попытки)» или «Тренировка (сессия)». Нужны калибровка и ноль в этой сессии. Первый раз показывается предупреждение о противопоказаниях. Попытка: 3 с до старта, красная рамка до срыва и возврата (не дольше 30 с), результат в см. Порог срыва: не меньше 3° и 3σ шума нуля. Сессия: замер «до» (3) → упражнение 1 (5) → замер «после» (3). В CSV столбцы `dev_inst` и `event` (`break`, `return`, `mark`).
