# Косоглазие: прототип M1

M0: камера → MediaPipe Face Landmarker → контуры и числа радужек, режим `isDev`.
M1: масштаб (размер радужки), личная модель лица, поза, угол каждого глаза, личный ноль, вергенция в ПД; тесты на синтетике (`src/core/`, `tests/`).
Следующие этапы (M2+) не начаты.

## Запуск
```
npm install        # создаст package-lock.json, его нужно закоммитить (CI использует npm ci)
npm run typecheck
npm test           # тесты математики на синтетических данных
npm run build      # esbuild → dist/; скачает модель face_landmarker.task в .cache/
npm run serve      # http://localhost:8080
```
Android: USB + `chrome://inspect`, проброс порта 8080 (камере нужен localhost или HTTPS) либо деплой на GitHub Pages.

## Деплой
Push в `main` → `.github/workflows/deploy.yml` (npm ci, сборка, официальные Pages-действия). В настройках репозитория: Pages → Source: GitHub Actions.

## Проверка M0 (главный риск плана)
1. Несколько людей без косоглазия: числа стабильны? Шум dx/dy в состоянии покоя (± в панели).
2. Сильно отклонённый глаз: окно «глаза» (кропы) показывает, лежит ли метка радужки на реальной радужке или «тянется» к типичному положению.
3. Сцены с меткой в CSV: «оба открыты», «правый закрыт», «левый закрыт», «срыв». Запись → CSV (только числа).

Соглашения: dx > 0 в сторону носа для обоих глаз, dy > 0 вверх; правый/левый по человеку; зеркалится только превью.
Вергенция (сведение/разведение) = R_dx + L_dx; версия (общий поворот взгляда) = R_dx − L_dx.

## Проверка M1 (порядок)
1. Метод масштаба: по умолчанию 11,7 мм; «по банковской карте»: карта у лица в плоскости глаз, жёлтая рамка по её ширине, кнопка «Определить радужку по карте»; допустимо 10–13,5 мм.
2. «Построить модель лица»: 8 с двигайте головой влево-вправо и вверх-вниз (не меньше ±6° по обеим осям), глаза в камеру. В панели: разброс < ~1 мм и «конв.».
3. «Задать ноль»: оба глаза на камеру, 2 с без морганий, одна дистанция (~40 см).
4. Сцены в CSV (метки): «оба в камеру», «срыв», «оба в камеру», с поворотом головы и с другой дистанцией. Новые столбцы: mm_px, z_mm, angR, angL, devR, devL, vergence, scale_method, iris_mm.

Соглашения M1: угол к носу > 0 для обоих глаз; вергенция = devR + devL (> 0 сведение, < 0 разведение). В плане «разность углов правого и левого глаза» (вправо > 0 для обоих глаз) это та же величина.
